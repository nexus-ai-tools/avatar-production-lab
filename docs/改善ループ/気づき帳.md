書き方と反映のしかたの正本は nexus-ai-skills の `shared/skills/knowhow-feedback-loop/SKILL.md`。

- 反映済みは「反映」の列に PR 番号か既存の場所、見送りは理由を書く。根拠が無いものは「未確認」と書き、反映しない。
